# Session moves for: Run two at once

Use `/batch` to hand two issues to separate agents in one go. Each agent gets its own copy of the app.

Save your session so the check can read it. Run this from the folder where you started `claude`:

```bash
bun run save-session parts/05-run-it-unattended/03-run-two-at-once/problem
```

Expect: a line that starts with Saved your newest session.
