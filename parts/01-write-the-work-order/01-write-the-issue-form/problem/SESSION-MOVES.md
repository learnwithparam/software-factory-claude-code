# Session moves for: Write the issue form

Try two habits in a session at the repo root. First, write one specific prompt: name the file, say what must
not change, and say when to stop. Then run `/clear` when the task is done, so the next task starts with a fresh
memory.

Save your session so the check can read it. Run this from the folder where you started `claude`:

```bash
bun run save-session parts/01-write-the-work-order/01-write-the-issue-form/problem
```

Expect: a line that starts with Saved your newest session.
